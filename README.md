# 同频 · 双人默契词语游戏

无需第三方依赖，使用 Node.js 18+ 内置 HTTP 服务。支持不同设备实时联机（Server-Sent Events）。

## 本地启动

```bash
npm start
```

打开 http://localhost:3000 ，一个人创建房间并选择每轮思考时间，另一人通过房间码/分享链接加入。

## 上线

将整个项目上传至支持 Node.js 常驻进程的托管服务（如 Render / Railway / Fly.io 等），启动命令为 `npm start`，平台会通过环境变量 `PORT` 指定监听端口。把分配的 HTTPS 链接分享给朋友。

## 游戏规则

- 房主设置每轮 15 / 30 / 45 / 60 / 90 / 120 / 180 秒。
- 两人独立输入，各自提交前对方仅看到提交状态，看不到词语。
- 两人都提交后同时揭晓；忽略首尾空格、大小写和 Unicode 宽度差异后判断是否匹配。
- 时间结束自动揭晓；未提交的玩家显示“未作答”。
- 不一样则展示结果 5 秒后自动开始下一轮；一样则获胜。
- 获胜后房主可以重新开局。

## 注意

这是适合朋友轻量游玩的版本：房间数据存储在服务进程内存中，服务重启会清空房间，多实例部署不共享数据；建议部署单实例。房间闲置 12 小时自动清理。若需要大量并发和持久化，可进一步接入 Redis / 数据库。
